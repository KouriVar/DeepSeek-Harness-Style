## 关键经验 / 坑
- `screencapture` 已获屏幕录制权限，可直接截图核对（`screencapture -x /tmp/x.png`）。
- 改右栏/侧栏偏移**不要用 `transform`**：会给内部 `position:fixed`(tooltip 等) 换包含块导致定位错乱。
- 设置页原生 `Switch`/`SegmentedControl` 不显示 `label`，必须自包文字。
- 顶栏 chip / 状态文案隐藏优先用**文本匹配 + 就近容器**，比依赖哈希类名稳。
- DSH 侧栏部分区域是插件/宿主渲染，类名（`kB3qhq_*` 等）随构建可能变；能靠语义锚点就不写死类名。
